## ⚠️ Common Issues

**Problem:** Image not showing
- [ ] Check filename matches exactly (case-sensitive!)
- [ ] Verify image is in correct folder
- [ ] Check file extension (.jpg vs .jpeg)
- [ ] Hard refresh browser (Ctrl+F5)

**Problem:** Image too large/slow
- [ ] Compress image (max 2MB recommended)
- [ ] Resize to recommended dimensions
- [ ] Convert to JPG if currently PNG

**Problem:** Gradient placeholder showing
- [ ] This is normal! It means image is missing
- [ ] Check the path shown in the placeholder
- [ ] Add the image to that exact location
